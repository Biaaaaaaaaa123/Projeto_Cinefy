# Cinefy

Landing page de uma plataforma de streaming fictícia, desenvolvida para apresentar planos de assinatura e destacar a experiência de assistir a filmes e séries em diferentes dispositivos.

O projeto foi inspirado em páginas comerciais de serviços como Netflix e HBO, com uma interface escura, chamadas para ação, seção de benefícios, compatibilidade com dispositivos e rodapé informativo.

## Objetivo

Praticar a criação de uma página web completa utilizando HTML e CSS, aplicando conceitos de:

- Estruturação semântica de páginas;
- Organização de conteúdo em seções;
- Layout com CSS Grid e Flexbox;
- Uso de variáveis CSS para padronização de cores;
- Imagens de fundo e elementos visuais;
- Estados de interação com `:hover`;
- Adaptação inicial da interface para diferentes tamanhos de tela.

## Funcionalidades

- Apresentação do serviço Cinefy;
- Destaque para planos de assinatura;
- Seção sobre a experiência de assistir em qualquer lugar;
- Exibição dos dispositivos compatíveis;
- Links de navegação e informações institucionais no rodapé;
- Efeito visual nos botões e links ao passar o mouse.

## Tecnologias utilizadas

- HTML5;
- CSS3;
- Google Fonts (Inter).

## Como executar

1. Clone ou baixe este repositório.
2. Abra a pasta do projeto no VS Code.
3. Abra o arquivo `index.html` no navegador.

Também é possível utilizar a extensão **Live Server** no VS Code para visualizar as alterações em tempo real.
